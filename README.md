# VetStation

VetStation is being prepared as a veterinary clinic website and operations platform. This repository currently contains the project foundation and product plan. Website pages and application features have not been started.

## Current status

- Git repository connected to `https://github.com/yousef-hamda/VetStation`.
- Product areas, roles, data boundaries, and implementation sequence are documented in [`docs/`](docs/).
- Framework, hosting, payment provider, and clinic workflows remain decisions to confirm before implementation.

## Start here

1. Review [product scope](docs/product-scope.md) and mark the modules needed for the first release.
2. Resolve the questions in [decisions](docs/decisions.md).
3. Follow the [implementation plan](docs/implementation-plan.md) when website development begins.

Do not commit patient data, credentials, or real environment files. Copy `.env.example` to `.env.local` only after infrastructure is selected.
